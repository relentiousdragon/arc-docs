---
title: "Boolean AND"
---

True when both inputs are true

## Inputs

| Pin Name | Pin Type | Default Value | undefined |
| :-: | :-: | :-: | :-: |
| A | boolean | false | First boolean value to test. |
| B | boolean | false | Second boolean value to test. |

## Outputs

| Pin Name | Pin Type | undefined |
| :-: | :-: | :-: |
| Result | boolean | True only when both inputs are true. |
