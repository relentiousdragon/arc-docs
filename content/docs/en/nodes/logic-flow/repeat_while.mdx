---
title: "Repeat While"
---

While Condition is true, waits at least 100 ms, runs Body once, and checks again. It can run indefinitely. Route changes through shared graph variables or other live inputs to stop it.

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Condition | boolean | true |
| Interval (ms) | number | 500 |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Body | exec |
| Completed | exec |
| Iteration | number |
