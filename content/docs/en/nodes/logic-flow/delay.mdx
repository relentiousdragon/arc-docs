---
title: "Wait (Async)"
---

Awaits a short timer for this run. Other Discord events and graph runs continue while it waits.

## Inputs

| Pin Name | Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Duration (ms) | number | 1000 |

## Outputs

| Pin Name | Type |
| :-: | :-: |
| Exec | exec |
