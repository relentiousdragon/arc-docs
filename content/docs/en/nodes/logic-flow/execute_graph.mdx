---
title: "Run Event Graph"
---

Runs another event graph for the same Discord event. The target must have a matching event node, graph cycles are rejected.

## Inputs

| Pin Name | Pin Type | Default Value | undefined |
| :-: | :-: | :-: | :-: |
| Exec | exec |  | Starts the matching event graph. |

## Outputs

| Pin Name | Pin Type | undefined |
| :-: | :-: | :-: |
| Exec | exec | Continues after the target graph finishes. |
