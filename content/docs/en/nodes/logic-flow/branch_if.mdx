---
title: "Branch (If / Else)"
---

Splits execution flow based on a boolean condition

## Inputs

| Pin Name | Pin Type | Default Value | undefined |
| :-: | :-: | :-: | :-: |
| Exec | exec |  | Evaluates the condition and selects an execution branch. |
| Condition | boolean | false | Boolean value used to choose the True or False branch. |

## Outputs

| Pin Name | Pin Type | undefined |
| :-: | :-: | :-: |
| True | exec | Runs when the condition is true. |
| False | exec | Runs when the condition is false. |
