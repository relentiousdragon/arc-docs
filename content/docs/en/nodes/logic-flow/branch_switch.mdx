---
title: "Switch / Case"
---

Compares one value with up to 50 cases and runs the first matching branch, or Default when none match.

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Value | arg |  |
| Case 1 | string |  |
| Case 2 | string |  |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Case 1 | exec |
| Case 2 | exec |
| Default | exec |
