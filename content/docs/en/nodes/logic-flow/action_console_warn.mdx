---
title: "Console Warn"
---

Writes a message to the Studio console at warn level.

## Inputs

| Pin Name | Pin Type | Default Value | undefined |
| :-: | :-: | :-: | :-: |
| Exec | exec |  | Writes the message to the warning log. |
| Message | string |  | Text to write to the Studio console. |

## Outputs

| Pin Name | Pin Type | undefined |
| :-: | :-: | :-: |
| Exec | exec | Continues after the warning is logged. |
