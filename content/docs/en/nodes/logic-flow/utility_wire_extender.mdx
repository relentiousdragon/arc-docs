---
title: "Wire Extender"
---

Passes execution or any typed data value straight through. Use it to route wires neatly around a busy canvas.

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Exec In | exec |  |
| Any Value 1 | any |  |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Exec Out | exec |
| Any Value 1 | any |
