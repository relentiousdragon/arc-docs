---
title: "Console Log"
---

Writes a message to the Studio console at info level.

## Inputs

| Pin Name | Pin Type | Default Value | undefined |
| :-: | :-: | :-: | :-: |
| Exec | exec |  | Writes the message to the info log. |
| Message | string |  | Text to write to the Studio console. |

## Outputs

| Pin Name | Pin Type | undefined |
| :-: | :-: | :-: |
| Exec | exec | Continues after the message is logged. |
