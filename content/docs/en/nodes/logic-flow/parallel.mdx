---
title: "Parallel"
---

Runs two execution branches concurrently. Both branches must connect to the same Join node before execution continues.

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Branch A | exec |
| Branch B | exec |
