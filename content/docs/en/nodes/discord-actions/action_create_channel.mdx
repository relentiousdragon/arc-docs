---
title: "Create Channel"
---

Creates a text, voice, category, announcement, or stage channel. Requires Manage Channels.

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Server ID | string |  |
| Name | string |  |
| Type | string | text |
| Category ID | string |  |
| Permission Overwrites | object |  |
| Topic | string |  |
| Audit Log Reason | string |  |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Exec | exec |
| Channel ID | string |
| Success | boolean |
