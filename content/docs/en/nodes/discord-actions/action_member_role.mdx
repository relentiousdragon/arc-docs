title: "Set Member Role"
---

Adds or removes a role from a guild member. Requires Manage Roles.

## Inputs

| Pin Name | Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Server ID | string |  |
| User ID | string |  |
| Role ID | string |  |
| Operation | string | add |
| Audit Log Reason | string |  |

## Outputs

| Pin Name | Type |
| :-: | :-: |
| Exec | exec |
| Success | boolean |
