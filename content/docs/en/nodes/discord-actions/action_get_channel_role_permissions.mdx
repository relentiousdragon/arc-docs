---
title: "Get Channel Role Permissions"
---

Gets a role's channel permissions together with @everyone, applying channel overwrites.

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Channel ID | string |  |
| Role ID | string |  |
| Apply Implicit Masking | boolean | true |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Exec | exec |
| Permissions Bitfield | string |
| Success | boolean |
