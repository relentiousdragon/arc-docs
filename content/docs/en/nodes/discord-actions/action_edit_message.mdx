---
title: "Edit Message"
---

Edits the content, embed, or components of an existing Discord message

## Inputs

| Pin Name | Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Channel ID | string |  |
| Message ID | string |  |
| Content | string |  |
| Embed (Optional) | embed |  |
| Components (Optional) | object |  |
| Files (optional) | object |  |

## Outputs

| Pin Name | Type |
| :-: | :-: |
| Exec | exec |
| Message ID | string |
| Success | boolean |
