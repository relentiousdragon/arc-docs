---
title: "Get Guild Role Permissions"
---

Gets a role's combined guild permissions together with the @everyone role.

## Inputs

| Pin Name | Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Server ID | string |  |
| Role ID | string |  |

## Outputs

| Pin Name | Type |
| :-: | :-: |
| Exec | exec |
| Permissions Bitfield | string |
| Success | boolean |
