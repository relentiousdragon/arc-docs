---
title: "Defer Update"
---

Acknowledge a button or select interaction now and update its message later. Connect Reply to Interaction after this node.

## Inputs

| Pin Name | Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Interaction ID | string |  |
| Interaction Token | string |  |

## Outputs

| Pin Name | Type |
| :-: | :-: |
| Exec | exec |
| Interaction Token | string |
| Interaction ID | string |
| Success | boolean |
