---
title: "Deploy Slash Commands"
---

Deploys workspace slash commands when triggered by a server manager with Manage Server or Administrator.

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Exec | exec |
| Commands Deployed | number |
| Succeeded | boolean |
| Error | string |
