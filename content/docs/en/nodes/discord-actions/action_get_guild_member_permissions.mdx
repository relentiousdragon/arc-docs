---
title: "Get Guild Member Permissions"
---

Gets a member's computed guild permissions from their roles and the @everyone role.

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Server ID | string |  |
| User ID | string |  |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Exec | exec |
| Permissions Bitfield | string |
| Success | boolean |
