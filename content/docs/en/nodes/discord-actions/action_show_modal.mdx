---
title: "Show Popup Modal"
---

Opens a configured Discord modal as the initial response to an interaction.

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Interaction ID | string |  |
| Interaction Token | string |  |
| Modal | object |  |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Exec | exec |
| Success | boolean |
