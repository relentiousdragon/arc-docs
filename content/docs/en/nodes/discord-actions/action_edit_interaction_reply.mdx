---
title: "Edit Interaction Reply"
---

Edits the original reply to a slash command, button, or select menu interaction after it has already been sent

## Inputs

| Pin Name | Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Application ID | string |  |
| Interaction Token | string |  |
| New Content (Optional) | string |  |
| Embed (Optional) | embed |  |
| Components (Optional) | object |  |
| Files (optional) | object |  |

## Outputs

| Pin Name | Type |
| :-: | :-: |
| Exec | exec |
| Success | boolean |
