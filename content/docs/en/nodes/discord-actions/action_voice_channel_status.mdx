---
title: "Set Voice Channel Status"
---

Sets or clears a voice channel status. Requires Set Voice Channel Status, Manage Channels may also be required.

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Voice Channel ID | string |  |
| Status (blank clears) | string |  |
| Audit Log Reason | string |  |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Exec | exec |
| Success | boolean |
