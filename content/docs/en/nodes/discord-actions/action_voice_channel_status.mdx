---
title: "Set Voice Channel Status"
---

Sets or clears a voice channel status. Requires Set Voice Channel Status, Manage Channels may also be required.

## Inputs

| Pin Name | Pin Type | Default Value | undefined |
| :-: | :-: | :-: | :-: |
| Exec | exec |  | Starts Set Voice Channel Status. |
| Voice Channel ID | string |  | ID of the voice channel to update. |
| Status (blank clears) | string |  | Status text to set, or blank to clear the current status. |
| Audit Log Reason | string |  | Reason recorded in the audit log. |

## Outputs

| Pin Name | Pin Type | undefined |
| :-: | :-: | :-: |
| Exec | exec | Continues after Set Voice Channel Status completes. |
| Success | boolean | Whether the action completed successfully. |
