---
title: "Moderate Member"
---

Times out, kicks, bans, or unbans a server member. Route failures through the Failed output.

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Server ID | string |  |
| User ID | string |  |
| Action | string | timeout |
| Timeout (minutes) | number | 10 |
| Ban message deletion (seconds) | number | 0 |
| Reason | string |  |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Succeeded | exec |
| Failed | exec |
| Success | boolean |
| Error | string |
