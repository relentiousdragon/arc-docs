title: "Set Presence"

Updates bot status, optional activity, and optional custom status

## Inputs

| Pin Name | Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Status (online/dnd/idle) | string | online |
| Activity Text | string | ARC Studio |
| Activity Type | number | 0 |
| Stream URL | string |  |
| Custom Status | string |  |

## Outputs

| Pin Name | Type |
| :-: | :-: |
| Exec | exec |
| Success | boolean |
