---
title: "Ceiling"
---

Rounds up to an integer

## Inputs

| Pin Name | Pin Type | Default Value | undefined |
| :-: | :-: | :-: | :-: |
| Value | number | 0 | Number to round up to the next integer. |

## Outputs

| Pin Name | Pin Type | undefined |
| :-: | :-: | :-: |
| Result | number | Input rounded up to an integer. |
