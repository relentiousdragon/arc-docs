---
title: "Arctangent"
---

Inverse tangent, returned in radians

## Inputs

| Pin Name | Pin Type | Default Value | undefined |
| :-: | :-: | :-: | :-: |
| Value | number | 0 | Tangent value to convert to an angle in radians. |

## Outputs

| Pin Name | Pin Type | undefined |
| :-: | :-: | :-: |
| Result | number | Angle in radians whose tangent is the input. |
