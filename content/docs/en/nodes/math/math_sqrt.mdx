---
title: "Square Root (√)"
---

Returns the non-negative square root, negative input returns 0

## Inputs

| Pin Name | Pin Type | Default Value | undefined |
| :-: | :-: | :-: | :-: |
| Value | number | 0 | Non-negative number whose square root to calculate. |

## Outputs

| Pin Name | Pin Type | undefined |
| :-: | :-: | :-: |
| Result | number | Non-negative square root, or zero for negative input. |
