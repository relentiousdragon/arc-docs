---
title: "Compare Numbers"
---

Compares two numbers and returns true or false

## Inputs

| Pin Name | Pin Type | Default Value | undefined |
| :-: | :-: | :-: | :-: |
| A | number | 0 | First number to compare. |
| B | number | 0 | Second number to compare. |

## Outputs

| Pin Name | Pin Type | undefined |
| :-: | :-: | :-: |
| Result | boolean | True when A and B match the selected comparison. |
