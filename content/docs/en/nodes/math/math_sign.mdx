---
title: "Sign"
---

Returns -1, 0, or 1 for the input sign

## Inputs

| Pin Name | Pin Type | Default Value | undefined |
| :-: | :-: | :-: | :-: |
| Value | number | 0 | Number whose sign to check. |

## Outputs

| Pin Name | Pin Type | undefined |
| :-: | :-: | :-: |
| Result | number | -1 for negative, 0 for zero, or 1 for positive input. |
