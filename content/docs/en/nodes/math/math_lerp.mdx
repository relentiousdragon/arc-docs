---
title: "Interpolate"
---

Linearly interpolates between A and B using a factor from 0 to 1

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| A | number | 0 |
| B | number | 1 |
| Factor | number | 0.5 |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Result | number |
