---
title: "Average"
---

Averages up to 50 values. Connect the last input to reveal another.

## Inputs

| Pin Name | Pin Type | Default Value | undefined |
| :-: | :-: | :-: | :-: |
| A | number | 0 | First number included in the average. |
| B | number | 0 | Second number included in the average. |

## Outputs

| Pin Name | Pin Type | undefined |
| :-: | :-: | :-: |
| Result | number | Arithmetic mean of the connected numbers. |
