---
title: "Evaluate"
---

Evaluates given expression

## Inputs

| Pin Name | Pin Type | Default Value | undefined |
| :-: | :-: | :-: | :-: |
| Expression | string |  | Arithmetic expression to evaluate. |

## Outputs

| Pin Name | Pin Type | undefined |
| :-: | :-: | :-: |
| Result | number | Numeric result of the expression. |
| Valid | boolean | True when the expression is valid. |
