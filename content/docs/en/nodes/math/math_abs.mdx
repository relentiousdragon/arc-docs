---
title: "Absolute (abs)"
---

Returns the distance from zero

## Inputs

| Pin Name | Pin Type | Default Value | undefined |
| :-: | :-: | :-: | :-: |
| Value | number | 0 | Number whose distance from zero to return. |

## Outputs

| Pin Name | Pin Type | undefined |
| :-: | :-: | :-: |
| Result | number | Non-negative distance of the input from zero. |
