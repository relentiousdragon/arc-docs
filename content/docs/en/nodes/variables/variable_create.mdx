---
title: "Create Variable"
---

Creates or updates a graph variable. Its value type follows the connected value, otherwise choose a type and fallback value.

## Inputs

| Pin Name | Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Value | arg |  |

## Outputs

| Pin Name | Type |
| :-: | :-: |
| Exec | exec |
| Variable | variable |
| Value | arg |
