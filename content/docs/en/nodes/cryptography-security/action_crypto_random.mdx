---
title: "Generate Crypto Token"
---

Generates secure cryptographic random hex, base64url tokens or numeric PINs

## Inputs

| Pin Name | Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Format (hex/base64url/pin) | string | hex |

## Outputs

| Pin Name | Type |
| :-: | :-: |
| Exec | exec |
| Token / PIN | string |
