---
title: "AES-256-GCM Encrypt"
---

Encrypts data using authenticated AES-256-GCM with PBKDF2

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Plaintext | string |  |
| Passphrase (Optional) | string |  |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Exec | exec |
| Encrypted Envelope | string |
