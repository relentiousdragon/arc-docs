---
title: "Cryptographic Hash"
---

Computes SHA-256 or SHA-512 cryptographic hash digests

## Inputs

| Pin Name | Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Input Data | string |  |
| Algorithm | string | sha256 |

## Outputs

| Pin Name | Type |
| :-: | :-: |
| Exec | exec |
| Hash Digest | string |
