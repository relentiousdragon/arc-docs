---
title: "Close WebSocket"
---

Closes an open WebSocket connection.

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Connection ID | string | main |
| Close Code | number | 1000 |
| Reason | string |  |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Closed | exec |
| Failed | exec |
| Closed | boolean |
| Error | string |
