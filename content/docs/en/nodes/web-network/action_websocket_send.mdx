---
title: "Send WebSocket Message"
---

Sends text or base64 encoded binary data through an open WebSocket connection.

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Connection ID | string | main |
| Message | string |  |
| Send as Binary | boolean | false |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Sent | exec |
| Failed | exec |
| Sent | boolean |
| Error | string |
