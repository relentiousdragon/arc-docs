---
title: "On WebSocket Open"
---

Runs when a WebSocket connection opens. Set Filter Connection ID to listen for one connection.

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Filter Connection ID | string |  |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Exec | exec |
| Connection ID | string |
| URL | string |
