---
title: "On Role Deleted"
---

A role is deleted. Discord sends only the server and role IDs.

## Outputs

| Pin Name | Pin Type | undefined |
| :-: | :-: | :-: |
| Exec | exec | Runs when a role is deleted. |
| Role ID | string | ID of the role tied to this event. |
| Server ID | string | ID of the server where the event occurred. |
