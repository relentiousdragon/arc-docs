---
title: "On WebSocket Error"
---

Runs when a WebSocket connection encounters an error. Set Filter Connection ID to listen for one connection.

## Inputs

| Pin Name | Type | Default Value |
| :-: | :-: | :-: |
| Filter Connection ID | string |  |

## Outputs

| Pin Name | Type |
| :-: | :-: |
| Exec | exec |
| Connection ID | string |
| Error | string |
| URL | string |
