---
title: "On Bot Startup"
---

Runs when bot startup begins. Optionally wait for the Gateway to connect.

## Inputs

| Pin Name | Type | Default Value |
| :-: | :-: | :-: |
| Wait for Gateway | boolean | false |
| Gateway Timeout (seconds) | number | 30 |

## Outputs

| Pin Name | Type |
| :-: | :-: |
| Exec | exec |
| Gateway Connected | boolean |
