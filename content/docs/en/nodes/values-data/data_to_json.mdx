---
title: "To JSON"
---

Serializes a value to compact JSON. Cyclic or unsupported values return an empty string and valid=false.

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Value | object |  |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| JSON | string |
| Valid | boolean |
