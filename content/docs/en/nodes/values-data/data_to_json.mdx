---
title: "To JSON"
---

Serializes a value to compact JSON. Cyclic or unsupported values return an empty string and valid=false.

## Inputs

| Pin Name | Type | Default Value |
| :-: | :-: | :-: |
| Value | object | null |

## Outputs

| Pin Name | Type |
| :-: | :-: |
| JSON | string |
| Valid | boolean |
