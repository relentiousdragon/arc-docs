---
title: "Find Array Item"
---

Finds the first item equal to Value. Set Path to compare a nested property, such as id or user.name.

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Array | object |  |
| Property path | string |  |
| Match value | arg |  |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Item | arg |
| Index | number |
| Found | boolean |
