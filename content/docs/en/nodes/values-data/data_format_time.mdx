---
title: "Format Date & Time"
---

Formats an ISO date or Unix millisecond timestamp using a locale, time zone, and date/time styles.

## Inputs

| Pin Name | Type | Default Value |
| :-: | :-: | :-: |
| Date / Timestamp | arg |  |
| Time zone | string | UTC |
| Date Format | string | DD/MM/YYYY - HH:mm:ss |
| Is Duration | boolean | false |

## Outputs

| Pin Name | Type |
| :-: | :-: |
| Formatted time | string |
| Valid | boolean |
