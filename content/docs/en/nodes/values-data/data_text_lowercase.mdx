---
title: "Lowercase Text"
---

Converts text to lowercase.

## Inputs

| Pin Name | Pin Type | Default Value | undefined |
| :-: | :-: | :-: | :-: |
| Text | string |  | Text to convert to lowercase. |

## Outputs

| Pin Name | Pin Type | undefined |
| :-: | :-: | :-: |
| Text | string | Input text converted to lowercase. |
