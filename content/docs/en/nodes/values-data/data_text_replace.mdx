---
title: "Replace Text"
---

Replaces every literal occurrence of a search string and reports how many replacements were made.

## Inputs

| Pin Name | Type | Default Value |
| :-: | :-: | :-: |
| Text | string |  |
| Find | string |  |
| Replace with | string |  |

## Outputs

| Pin Name | Type |
| :-: | :-: |
| Text | string |
| Replacements | number |
