---
title: "Edit Array Item"
---

Returns a copy of the array with an existing zero-based index replaced. The source array is unchanged.

## Inputs

| Pin Name | Type | Default Value |
| :-: | :-: | :-: |
| Array | object |  |
| Index | number | 0 |
| New Item | arg | null |

## Outputs

| Pin Name | Type |
| :-: | :-: |
| Array | object |
| Updated | boolean |
