---
title: "Check Value"
---

Distinguishes missing, null, empty text, and real values. The Value output uses the fallback unless a real value is present.

## Inputs

| Pin Name | Type | Default Value |
| :-: | :-: | :-: |
| Value | arg |  |
| Fallback | arg |  |

## Outputs

| Pin Name | Type |
| :-: | :-: |
| Value or fallback | arg |
| State | string |
| Missing | boolean |
| Null | boolean |
| Empty text | boolean |
| Has value | boolean |
