---
title: "Get Object Property"
---

Reads a property by key. Check Exists to distinguish a missing property from an empty value.

## Inputs

| Pin Name | Type | Default Value |
| :-: | :-: | :-: |
| Object | object | [object Object] |
| Property | string |  |

## Outputs

| Pin Name | Type |
| :-: | :-: |
| Value | arg |
| Exists | boolean |
