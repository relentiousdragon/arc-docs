---
title: "Trim Text"
---

Removes whitespace from the start and end of text.

## Inputs

| Pin Name | Pin Type | Default Value | undefined |
| :-: | :-: | :-: | :-: |
| Text | string |  | Text to trim. |

## Outputs

| Pin Name | Pin Type | undefined |
| :-: | :-: | :-: |
| Text | string | Input text without whitespace at the start or end. |
