---
title: "Set Object Property"
---

Returns a copy of an object with the selected property added or replaced.

## Inputs

| Pin Name | Pin Type | Default Value | undefined |
| :-: | :-: | :-: | :-: |
| Object | object | [object Object] | Object to copy and update. |
| Property | string |  | Property name to add or replace. |
| Value | arg |  | Value to assign to the property. |

## Outputs

| Pin Name | Pin Type | undefined |
| :-: | :-: | :-: |
| Object | object | Copy of the object with the selected property set. |
