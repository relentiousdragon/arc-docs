---
title: "Get Array Item"
---

Reads an item by its zero-based index. Check Found before using the result.

## Inputs

| Pin Name | Type | Default Value |
| :-: | :-: | :-: |
| Array | object |  |
| Index | number | 0 |

## Outputs

| Pin Name | Type |
| :-: | :-: |
| Item | arg |
| Found | boolean |
