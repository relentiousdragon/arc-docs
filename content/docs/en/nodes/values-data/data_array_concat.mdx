---
title: "Combine Arrays"
---

Concatenates connected arrays in input order into a new array. Use another Create Array node for more than 50 individual items.

## Inputs

| Pin Name | Type | Default Value |
| :-: | :-: | :-: |
| Array 1 | object |  |
| Array 2 | object |  |

## Outputs

| Pin Name | Type |
| :-: | :-: |
| Array | object |
| Length | number |
