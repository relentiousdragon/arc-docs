---
title: "Uppercase Text"
---

Converts text to uppercase.

## Inputs

| Pin Name | Pin Type | Default Value | undefined |
| :-: | :-: | :-: | :-: |
| Text | string |  | Text to convert to uppercase. |

## Outputs

| Pin Name | Pin Type | undefined |
| :-: | :-: | :-: |
| Text | string | Input text converted to uppercase. |
