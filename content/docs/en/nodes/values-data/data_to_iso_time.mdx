---
title: "To ISO Date"
---

Converts an ISO date or Unix millisecond timestamp to a UTC ISO 8601 string.

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Date / timestamp | string |  |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| ISO date | string |
| Valid | boolean |
