---
title: "Format Number"
---

Formats a finite number with locale grouping, decimal, percent, or currency style. Percent style scales the number by 100.

## Inputs

| Pin Name | Type | Default Value |
| :-: | :-: | :-: |
| Value | number | 0 |
| Locale | string | en-US |
| Style | string | decimal |
| Currency | string | USD |
| Minimum decimals | number | 0 |
| Maximum decimals | number | 2 |

## Outputs

| Pin Name | Type |
| :-: | :-: |
| Formatted | string |
| Valid | boolean |
