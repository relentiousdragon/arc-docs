---
title: "Parse Prefix Command"
---

Checks for a prefix, extracts the command, and parses whitespace-separated arguments. Quoted arguments can contain spaces.

## Inputs

| Pin Name | Type | Default Value |
| :-: | :-: | :-: |
| Message Content | string |  |
| Prefix | string | ! |

## Outputs

| Pin Name | Type |
| :-: | :-: |
| Recognized | boolean |
| Command | string |
| Arguments | object |
| Argument Count | number |
