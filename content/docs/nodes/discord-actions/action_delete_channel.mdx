---
title: "Delete Channel"
---

Permanently deletes a channel. This cannot be undone. Requires Manage Channels.

## Inputs

| Pin Name | Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Channel ID | string |  |
| Audit Log Reason | string |  |

## Outputs

| Pin Name | Type |
| :-: | :-: |
| Exec | exec |
| Deleted Channel ID | string |
| Success | boolean |
