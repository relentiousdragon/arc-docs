---
title: "On WebSocket Close"
---

Runs when a WebSocket connection closes. Set Filter Connection ID to listen for one connection.

## Inputs

| Pin Name | Type | Default Value |
| :-: | :-: | :-: |
| Filter Connection ID | string |  |

## Outputs

| Pin Name | Type |
| :-: | :-: |
| Exec | exec |
| Connection ID | string |
| Code | number |
| Reason | string |
| Was Clean | boolean |
