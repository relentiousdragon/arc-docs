---
title: "To Boolean"
---

Converts booleans, numbers, and common text values (true/false, yes/no, 1/0, on/off). Unknown text returns false; check Valid.

## Inputs

| Pin Name | Type | Default Value |
| :-: | :-: | :-: |
| Value | arg | false |

## Outputs

| Pin Name | Type |
| :-: | :-: |
| Boolean | boolean |
| Valid | boolean |
