---
title: "Request Voice Join / Leave"
---

Requests a Gateway voice-state change. Joining does not create an audio connection or play audio.

## Inputs

| Pin Name | Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Server ID | string |  |
| Voice Channel ID (blank leaves) | string |  |
| Self Mute | boolean | false |
| Self Deafen | boolean | false |

## Outputs

| Pin Name | Type |
| :-: | :-: |
| Exec | exec |
| Success | boolean |
