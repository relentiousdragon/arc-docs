---
title: "AES-256-GCM Decrypt"
---

Decrypts and verifies AES-256-GCM authenticated envelopes

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | undefined |
| :-: | :-: | :-: | :-: |
| Exec | exec |  | Starts decryption of the encrypted envelope. |
| Encrypted Envelope | string |  | AES-256-GCM envelope to decrypt and authenticate. |
| Passphrase (Optional) | string |  | Optional passphrase used to derive the decryption key. |

## Výstupy

| Názov Pinu | Typ Pinu | undefined |
| :-: | :-: | :-: |
| Exec | exec | Continues after decryption finishes. |
| Plaintext | string | Authenticated plaintext from the envelope. |
