---
title: "Wait Until Time"
---

Waits until an ISO date/time or Unix timestamp in milliseconds. Maximum wait is 7 days.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | undefined |
| :-: | :-: | :-: | :-: |
| Exec | exec |  | Starts waiting for the target time. |
| Time (ISO or ms) | string |  | ISO date or Unix timestamp in milliseconds to wait for. |

## Výstupy

| Názov Pinu | Typ Pinu | undefined |
| :-: | :-: | :-: |
| Exec | exec | Continues when the target time is reached. |
