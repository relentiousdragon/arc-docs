---
title: "Wait (Async)"
---

Awaits a short timer for this run. Other Discord events and graph runs continue while it waits.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | undefined |
| :-: | :-: | :-: | :-: |
| Exec | exec |  | Starts the asynchronous wait. |
| Duration (ms) | number | 1000 | Time to wait before continuing, in milliseconds. |

## Výstupy

| Názov Pinu | Typ Pinu | undefined |
| :-: | :-: | :-: |
| Exec | exec | Continues after the wait completes. |
