---
title: "Join"
---

Waits for both branches from one Parallel node, then continues once. For mutually exclusive If/Else paths, connect their exec wires directly to the same action node.

## Inputs

| Názov Pinu | Typ Pinu | Predvolená Hodnota |
| :-: | :-: | :-: |
| Exec | exec |  |

## Outputs

| Názov Pinu | Typ Pinu |
| :-: | :-: |
| Exec | exec |
