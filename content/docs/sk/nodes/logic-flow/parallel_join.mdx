---
title: "Join"
---

Waits for all concurrent branches from one Parallel node, then continues once. For mutually exclusive If/Else paths, connect their exec wires directly to the same action node.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | undefined |
| :-: | :-: | :-: | :-: |
| Exec | exec |  | Receives a completed branch from the matching Parallel node. |

## Výstupy

| Názov Pinu | Typ Pinu | undefined |
| :-: | :-: | :-: |
| Exec | exec | Continues once every branch has reached this Join node. |
