---
title: "For Count"
---

Runs the Body branch once per iteration, then continues from Completed. Iterations are capped at 1,000 per run.

## Inputs

| Názov Pinu | Typ Pinu | Predvolená Hodnota |
| :-: | :-: | :-: |
| Exec | exec |  |
| Count | number | 1 |

## Outputs

| Názov Pinu | Typ Pinu |
| :-: | :-: |
| Body | exec |
| Completed | exec |
| Index (0-based) | number |
