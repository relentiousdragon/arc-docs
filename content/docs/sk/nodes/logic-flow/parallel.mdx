---
title: "Parallel"
---

Runs two execution branches concurrently. Both branches must connect to the same Join node before execution continues.

## Inputs

| Názov Pinu | Typ Pinu | Predvolená Hodnota |
| :-: | :-: | :-: |
| Exec | exec |  |

## Outputs

| Názov Pinu | Typ Pinu |
| :-: | :-: |
| Branch A | exec |
| Branch B | exec |
