---
title: "Compare Text"
---

Compares two text strings (equals, contains, startsWith)

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Text A | string | Žiadna | First text value to compare. |
| Text B | string | Žiadna | Second text value to compare. |
| Operator | string | equals | Comparison to perform on the two text values. |
| Ignore Case | boolean | Žiadna | Compare text without distinguishing uppercase and lowercase letters. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Result | boolean | True when the selected text comparison matches. |
