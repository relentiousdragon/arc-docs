---
title: "Set Variable"
---

Updates a graph variable during execution

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | undefined |
| :-: | :-: | :-: | :-: |
| Exec | exec |  | Starts updating the variable. |
| Variable | variable |  | Variable to update. |
| Value | string |  | New value to store in the variable. |

## Výstupy

| Názov Pinu | Typ Pinu | undefined |
| :-: | :-: | :-: |
| Exec | exec | Continues after the variable is updated. |
| Variable | variable | Reference to the updated variable. |
