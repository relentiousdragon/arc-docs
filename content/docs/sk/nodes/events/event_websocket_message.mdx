---
title: "On WebSocket Message"
---

Runs when a WebSocket message arrives. Binary data is provided as base64. Set Filter Connection ID to listen for one connection.

## Inputs

| Názov Pinu | Typ Pinu | Predvolená Hodnota |
| :-: | :-: | :-: |
| Filter Connection ID | string |  |

## Outputs

| Názov Pinu | Typ Pinu |
| :-: | :-: |
| Exec | exec |
| Connection ID | string |
| Message | string |
| Is Binary | boolean |
| Byte Length | number |
| URL | string |
