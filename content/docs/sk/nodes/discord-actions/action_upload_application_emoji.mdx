---
title: "Upload Bot Emoji"
---

Uploads an emoji to the bot application. Requires a PNG, JPEG, GIF, or WebP image no larger than 256 KiB.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | undefined |
| :-: | :-: | :-: | :-: |
| Exec | exec |  | Starts Upload Bot Emoji. |
| Emoji Name | string |  | Name to assign. |
| Image File | object |  | Files to attach to the message. |

## Výstupy

| Názov Pinu | Typ Pinu | undefined |
| :-: | :-: | :-: |
| Exec | exec | Continues after Upload Bot Emoji completes. |
| Emoji ID | string | ID of the created emoji. |
| Emoji Name | string | Name of the created emoji. |
| Success | boolean | Whether the action completed successfully. |
