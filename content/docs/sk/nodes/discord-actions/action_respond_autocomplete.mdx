---
title: "Respond to Autocomplete"
---

Returns up to 25 suggestions from a wired array of name and value objects.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | undefined |
| :-: | :-: | :-: | :-: |
| Exec | exec |  | Starts Respond to Autocomplete. |
| Interaction ID | string |  | ID of the interaction to respond to. |
| Interaction Token | string |  | Token used to respond to the interaction. |
| Suggestions | object |  | Suggestions to return for the focused command option. |

## Výstupy

| Názov Pinu | Typ Pinu | undefined |
| :-: | :-: | :-: |
| Exec | exec | Continues after Respond to Autocomplete completes. |
| Suggestions Sent | number | Number of suggestions sent to Discord. |
| Success | boolean | Whether the action completed successfully. |
