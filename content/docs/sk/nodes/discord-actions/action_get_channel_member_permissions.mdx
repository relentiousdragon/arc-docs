---
title: "Get Channel Member Permissions"
---

Gets a member's channel permissions, including role and member overwrites.

## Inputs

| Názov Pinu | Typ Pinu | Predvolená Hodnota |
| :-: | :-: | :-: |
| Exec | exec |  |
| Channel ID | string |  |
| User ID | string |  |
| Apply Implicit Masking | boolean | true |

## Outputs

| Názov Pinu | Typ Pinu |
| :-: | :-: |
| Exec | exec |
| Permissions Bitfield | string |
| Success | boolean |
