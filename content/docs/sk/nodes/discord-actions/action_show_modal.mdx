---
title: "Show Popup Modal"
---

Opens a configured Discord modal as the initial response to an interaction.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | undefined |
| :-: | :-: | :-: | :-: |
| Exec | exec |  | Starts Show Popup Modal. |
| Interaction ID | string |  | ID of the interaction to respond to. |
| Interaction Token | string |  | Token used to respond to the interaction. |
| Modal | object |  | Modal definition to show to the user. |

## Výstupy

| Názov Pinu | Typ Pinu | undefined |
| :-: | :-: | :-: |
| Exec | exec | Continues after Show Popup Modal completes. |
| Success | boolean | Whether the action completed successfully. |
