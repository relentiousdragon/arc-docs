---
title: "Create Role"
---

Creates a role with a name, RGB color number, and mentionable setting. Requires Manage Roles.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota |
| :-: | :-: | :-: |
| Exec | exec |  |
| Server ID | string |  |
| Name | string | new role |
| Color (RGB number) | number | 0 |
| Permissions Bitfield | string | 0 |
| Show separately | boolean | false |
| Mentionable | boolean | false |
| Audit Log Reason | string |  |
