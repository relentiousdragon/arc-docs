---
title: "Delete Channel"
---

Permanently deletes a channel. This cannot be undone. Requires Manage Channels.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | undefined |
| :-: | :-: | :-: | :-: |
| Exec | exec |  | Starts Delete Channel. |
| Channel ID | string |  | ID of the channel to delete. |
| Audit Log Reason | string |  | Reason recorded in the audit log. |

## Výstupy

| Názov Pinu | Typ Pinu | undefined |
| :-: | :-: | :-: |
| Exec | exec | Continues after Delete Channel completes. |
| Deleted Channel ID | string | ID of the channel deleted by the action. |
| Success | boolean | Whether the action completed successfully. |
