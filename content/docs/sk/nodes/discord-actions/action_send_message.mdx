---
title: "Send Message"
---

Sends message text, embeds, attachments, and interactive components to a Discord channel

## Inputs

| Názov Pinu | Typ Pinu | Predvolená Hodnota |
| :-: | :-: | :-: |
| Exec | exec |  |
| Channel ID | string |  |
| Thread ID (Optional) | string |  |
| Content | string |  |
| Embed (Optional) | embed |  |
| Components (Optional) | object |  |
| Files (optional) | object |  |
| File Data URL / Base64 | string |  |
| File Name | string | image.png |
| Reply to Message ID | string |  |
| Mention Replied User | boolean | false |

## Outputs

| Názov Pinu | Typ Pinu |
| :-: | :-: |
| Exec | exec |
| Message ID | string |
| Success | boolean |
