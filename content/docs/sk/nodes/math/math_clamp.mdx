---
title: "Clamp"
---

Restricts a value between a minimum and maximum

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | undefined |
| :-: | :-: | :-: | :-: |
| Value | number | 0 | Number to restrict to the selected range. |
| Minimum | number | 0 | Lowest allowed result. |
| Maximum | number | 1 | Highest allowed result. |

## Výstupy

| Názov Pinu | Typ Pinu | undefined |
| :-: | :-: | :-: |
| Result | number | Input limited to the minimum and maximum. |
