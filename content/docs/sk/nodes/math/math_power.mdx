Raises A to the power of B

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | undefined |
| :-: | :-: | :-: | :-: |
| A | number | 0 | Number to raise to a power. |
| B | number | 0 | Exponent to raise A by. |

## Výstupy

| Názov Pinu | Typ Pinu | undefined |
| :-: | :-: | :-: |
