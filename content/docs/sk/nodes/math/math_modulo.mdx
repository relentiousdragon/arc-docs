---
title: "Remainder (mod)"
---

Returns the remainder after division

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | undefined |
| :-: | :-: | :-: | :-: |
| A | number | 0 | Number to divide. |
| B | number | 0 | Number to divide by. |

## Výstupy

| Názov Pinu | Typ Pinu | undefined |
| :-: | :-: | :-: |
| Result | number | Remainder after dividing A by B. |
