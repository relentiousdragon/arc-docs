---
title: "Get Value by Path"
---

Safely reads a nested object or array path such as user.profile.name or items[0].id. Check Exists when the path may be missing.

## Inputs

| Názov Pinu | Typ Pinu | Predvolená Hodnota |
| :-: | :-: | :-: |
| Object / Array | object | [object Object] |
| Path | string |  |
| Fallback | arg |  |

## Outputs

| Názov Pinu | Typ Pinu |
| :-: | :-: |
| Value or fallback | arg |
| Exists | boolean |
