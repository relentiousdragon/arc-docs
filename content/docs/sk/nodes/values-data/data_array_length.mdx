---
title: "Array Length"
---

Returns the number of items in an array and whether it is empty.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | undefined |
| :-: | :-: | :-: | :-: |
| Array | object |  | Array whose length and empty state to check. |

## Výstupy

| Názov Pinu | Typ Pinu | undefined |
| :-: | :-: | :-: |
| Length | number | Number of items in the array. |
| Is Empty | boolean | True when the array has no items. |
