---
title: "Split Text"
---

Splits text at each exact separator string. Connect Part 1, Part 2, and more as needed, each used output reveals the next socket. It does not parse command prefixes or quoted arguments.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | undefined |
| :-: | :-: | :-: | :-: |
| Text | string |  | Text to split. |
| Separator | string | , | Exact text separator to split at. |

## Výstupy

| Názov Pinu | Typ Pinu | undefined |
| :-: | :-: | :-: |
| Parts | object | Parts of the input text in order. |
| Count | number | Number of parts created. |
