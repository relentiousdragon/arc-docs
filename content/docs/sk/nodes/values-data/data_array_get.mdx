---
title: "Get Array Item"
---

Reads an item by its zero-based index. Check Found before using the result.

## Inputs

| Názov Pinu | Typ Pinu | Predvolená Hodnota |
| :-: | :-: | :-: |
| Array | object |  |
| Index | number | 0 |

## Outputs

| Názov Pinu | Typ Pinu |
| :-: | :-: |
| Item | arg |
| Found | boolean |
