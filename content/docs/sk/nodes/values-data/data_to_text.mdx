---
title: "To Text"
---

Converts a value to text. Objects and arrays become JSON, null becomes empty text. Check Valid if the value cannot be serialized.

## Inputs

| Názov Pinu | Typ Pinu | Predvolená Hodnota |
| :-: | :-: | :-: |
| Value | arg |  |

## Outputs

| Názov Pinu | Typ Pinu |
| :-: | :-: |
| Text | string |
| Valid | boolean |
