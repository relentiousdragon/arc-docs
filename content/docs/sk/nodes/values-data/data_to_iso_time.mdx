---
title: "To ISO Date"
---

Converts an ISO date or Unix millisecond timestamp to a UTC ISO 8601 string.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | undefined |
| :-: | :-: | :-: | :-: |
| Date / timestamp | string |  | ISO date or Unix timestamp in milliseconds to convert. |

## Výstupy

| Názov Pinu | Typ Pinu | undefined |
| :-: | :-: | :-: |
| ISO date | string | Date and time converted to UTC ISO 8601 text. |
| Valid | boolean | True when the input is a valid date or timestamp. |
