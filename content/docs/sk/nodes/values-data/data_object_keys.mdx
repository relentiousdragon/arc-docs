---
title: "Object Keys"
---

Returns the enumerable property names of an object as an array.

## Inputs

| Názov Pinu | Typ Pinu | Predvolená Hodnota |
| :-: | :-: | :-: |
| Object | object | [object Object] |

## Outputs

| Názov Pinu | Typ Pinu |
| :-: | :-: |
| Keys | object |
| Length | number |
