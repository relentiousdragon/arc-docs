---
title: "Text to Number"
---

Parses a complete decimal number, including sign and exponent. Invalid or non-finite input returns 0, check Valid before using it.

## Inputs

| Názov Pinu | Typ Pinu | Predvolená Hodnota |
| :-: | :-: | :-: |
| Text | string |  |

## Outputs

| Názov Pinu | Typ Pinu |
| :-: | :-: |
| Number | number |
| Valid | boolean |
