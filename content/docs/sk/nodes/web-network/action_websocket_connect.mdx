---
title: "Connect WebSocket"
---

Opens a WebSocket connection to a public host and waits until it is ready.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota |
| :-: | :-: | :-: |
| Exec | exec |  |
| Connection ID | string | main |
| WebSocket URL | string |  |
| Protocols | string |  |
| Connect Timeout (ms) | number | 10000 |
